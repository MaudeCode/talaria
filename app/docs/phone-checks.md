# Phone checks

Talaria's automated tests run in process: hosted presentation tests in `TalariaTests` and TalariaKit unit tests
(TAL-856). They cover what the App does with a gesture, a system sheet or a launch, but not the system delivering it.
The flows below need a signed build installed on a real device. Run the ones a release's
changes touch before it ships.

| Flow | Check on the phone | In-process coverage |
|---|---|---|
| Cold launch on a slow network | Restore the last chat synchronously from cached summaries before network loads. With no cached match, keep an idle New Chat root after the list answers; keyboard stays down and no session is created. | TalariaKit `SessionListMutationTests`, `SessionNavigationStateTests`; `SessionListHostedTests.testRelaunchShowsTheLastChatsBeforeTheServerAnswers` |
| Pending chat and project changes | Pin/unpin, rename/move, archive and Undo, then create/rename/recolor/delete a disposable project. Confirm bulk deletion before rows change. | `SessionListHostedTests.testPendingPinIsVisibleBeforeTheServerAnswers`, TalariaKit `SessionListPendingChangeTests` |
| Row swipe to archive | Swipe a chat left, tap Archive, then Undo on the toast | `SessionListHostedTests.testUndoRestoresAnArchivedChat` |
| Current chat actions | Tap the chat title at compact and regular widths. Compare its actions with the row's long-press menu. On Duo inner landscape, More opens the same list and folds before the bell; the bell stays visible. An unsent New Chat has no session actions. | `SessionListHostedTests`, `ToolbarPriorityHostedTests.testChatMoreFoldsBeforeTheBellOnDuoInnerLandscape` |
| Saving transcript audio | In a chat with an audio tile, tap Export and save it to Files | `ChatHostedTests.testServerMediaRendersInsideTheMarkdownAroundIt` (the exporter opens) |

| Editing a pending steer with the keyboard up | Type a draft, then tap Edit on a pending steer: the steer joins the draft | `ChatHostedTests.testPendingSteerFromAnotherDeviceOffersSendNowEditAndCancel` |

| Sidebar controls | Open the sidebar: Search and New Chat remain reachable in its system bar. Tap Search or pull past the ring threshold: the field replaces the wordmark, autofocuses, filters results and closes with X. A short pull cancels. Fold/unfold keeps the field and query together. | `SessionListHostedTests`, `ToolbarPriorityHostedTests` |
