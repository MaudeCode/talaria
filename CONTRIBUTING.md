# Contributing to Talaria

> [!WARNING]
> **Talaria is not accepting outside contributions.** The project is under heavy,
> fast-moving development: interfaces, storage formats, and release flows change
> without notice. This file will say so when that changes.

## Security

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

## Building for yourself

You can still build and run Talaria from source: see [app development](app/DEVELOPMENT.md)
(including [signing with your own Apple team](app/DEVELOPMENT.md#signing-with-your-own-apple-team)),
the [Talaria Web README](web/README.md), and the [Relay README](relay/README.md).

## Maintainers and agents

The internal workflow (tracker, branches, validation, and release notes) is in
[AGENTS.md](AGENTS.md) and each component's `AGENTS.md`.

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
